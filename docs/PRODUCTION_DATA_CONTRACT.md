# Production Data Contract

Generated by `python scripts/build_production_docs.py` on 2026-10-07. Do not edit by hand: change the table in the script or the records it reads, and build again.

Every value the customer application shows, with its origin. A value that is not in this table must not be on a page. The pages read static files written by `airpulse-web/scripts/export_data.py`; the browser calls no provider and holds no key.

Kinds: **observed** (published by a source and shown as published), **calculated** (arithmetic on observed values or on run records), **forecast** (issued by the engine and kept in an append-only ledger), **test result** (stored result of an evaluation, with its date), **configuration** (a fixed setting or definition).

## Rules that hold for every row

- **Export time.** Every file is written in one export whose time is `core.generated_at`. The export is staged, checked and only then moved into place; `core.export.content_hash` identifies its logical content.
- **No silent fallback.** A source that fails keeps its last validated file; its state is said in three places (top bar, the page, the Data page). No value is replaced by a sample, a default or an earlier forecast presented as current.
- **Staleness is computed, twice.** Once by the engine at export (`src/observability/registry.py`) and again in the browser when a page is opened, from the same fields, so an old export cannot look fresh.
- **Missing is not zero.** A period a source did not cover is absent.
